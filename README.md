# CleanSlate — удаление программ и их остатков (Windows 11 x64)

Стек: **C# / .NET 8 / WPF**, без сторонних библиотек в приложении. Интерфейс на русском, работает локально.

## Сборка и запуск
Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download) на Windows.

```powershell
dotnet run --project CleanSlate.App
dotnet publish CleanSlate.App -c Release -r win-x64 --self-contained -o publish   # готовый CleanSlate.exe
dotnet test CleanSlate.Tests
```

## Структура
| Проект | Что внутри |
|---|---|
| `CleanSlate.Core` | реестр программ, поиск остатков, `SafetyGuard`, очистка, журнал, настройки |
| `CleanSlate.App` | WPF: боковая панель, «Программы / Остатки / Журнал / Настройки», диалоги подтверждения и отчёта |
| `CleanSlate.Tests` | xUnit-тесты на временных папках `TestGame`, `TestGameBackup` и др. |
| `tools/Create-TestGame.ps1` | ручной стенд: создаёт тестовую «игру» с записью в реестре и рабочим деинсталлятором |

## Как работает проверка принадлежности (п. 4 ТЗ)
* Совпадение имени папки **не считается доказательством**. Папка получает статус «подтверждено» (и отмечается по умолчанию) только при точном совпадении имени **плюс** второй признак: каталог издателя в пути (`...\Издатель\Игра`) или файл внутри, ссылающийся на путь установки/издателя.
* Всё остальное (частичное совпадение вроде `TestGameBackup`, только имя, программа без издателя) — «не подтверждено», не отмечено; пользователь может отметить вручную.
* `SafetyGuard` проверяет путь дважды (при поиске и непосредственно перед удалением): запрещены корни дисков, Windows, Program Files, ProgramData, профиль, сами корни поиска, общие имена (`Microsoft`, `Packages`, `Temp`…), ссылки/junction, каталог самой программы.
* Удаление только после окна подтверждения со списком путей и суммарным размером; Корзина не используется.
* Права администратора не запрашиваются; отказ в доступе, занятые файлы и т. п. попадают в отчёт и журнал, остальные папки обрабатываются дальше.
* Журнал: `%LOCALAPPDATA%\CleanSlate\logs\cleanslate-ГГГГММДД.log` и раздел «Журнал».

## Ручной приёмочный сценарий
1. `powershell -ExecutionPolicy Bypass -File tools\Create-TestGame.ps1`
2. Запустить CleanSlate → «Обновить список» → выбрать **TestGame**.
3. Проверить: найдены 5 каталогов данных + каталог установки; `TestGameBackup` — «не подтверждено», без галочки; `Saved Games\TestGame` — «не подтверждено».
4. «Удалить программу» → отмена в окне подтверждения → ничего не изменилось.
5. Повторить и подтвердить → запустится деинсталлятор, предложат найти остатки → раздел «Остатки» → удалить отмеченное. `TestGameBackup` должен остаться.
6. Раздел «Остатки» вручную: ввести `TestGame` без издателя → всё «не подтверждено».
7. Уборка: `Create-TestGame.ps1 -Remove`.

## Ограничения
* Версия не искала и не чистила реестр, службы, облачные сохранения (п. 6 ТЗ).
* Поиск идёт на глубину «корень\папка» и «корень\издатель\папка». Данные в более глубоких или нестандартных местах не находятся.
* Если сборка не проходит или тест ведёт себя иначе — пришлите вывод, поправим.
